# {{ project-name }}

A basic Rust service generated by the p6m archetype ecosystem. It ships with the platform
foundations (health/management endpoints, observability, CI/CD, Docker, Kubernetes manifests)
and a single HTTP stub endpoint, ready to grow domain logic and resources.

## Development

```bash
# Run locally
just run

# Run with Tilt (full local stack)
tilt up

# Build
cargo build

# Install binary
just install
```

## Endpoints

- `GET /` (service port) — service identity stub; replace with your application routes.
- `GET /health/readiness`, `GET /health/liveness`, `GET /metrics` (management port).
